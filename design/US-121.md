# US-121 · Generator tools for agents

## Approach
Three tools in `server/src/tools.ts`'s sibling `server/src/generators.ts` (tools.ts
is 634 lines; it would pass 1000). They call the same core functions as the panels.
- `ProjectFolder.writeGenerated(rel, data)` is the only new way to write a file. It
  accepts paths under `generated/` only, ends in `.png`, and never replaces: a taken
  name gets `-2`, `-3`... It returns the path used.
- The collision-class step of the tileset panel (find or add slope classes, name the
  class per kind, leave out the project's first class) moves to core as
  `tilegenCollisionClasses(sheet, classes)`, returning the collision map and the
  classes list; the panel and the tool both call it.
- `tileset_generate`: preset id (or none) + overrides of `TilegenOptions`, block size,
  seed. Writes the PNG, saves the tileset, adds slope classes to `project.json`.
- `room_generate`: style id + `RoomgenOptions` overrides, tileset id. Reads the
  tileset PNG for its layout (`tilegenLayout`), the project's physics for the jump
  (`platformerFigures`), saves the room, renders it.
- `pixel_art_convert`: source PNG path, name, converter options. Writes the result.
Alternatives: write generated PNGs under `assets/` (rejected by the author: that
folder is the author's); one tool for all three (rejected: different inputs).

## Format changes
None. `generated/` is an ordinary folder: the asset list already walks it, and
documents refer to images by path.

## Hardware cost
None at runtime. Tilesets are at most 15 colours, so one palette, as the generator
already guarantees.

## Tests
- tileset_generate: `server/test/generators.test.ts` (document, PNG, slope classes, picture, no problems).
- room_generate: same file (room saved, no problems; clear error on a foreign tileset).
- pixel_art_convert: same file (size, colours, file under `generated/pixelart/`).
- Writes confined, no overwrite: same file (a second call gives `-2`; `writeGenerated` refuses `assets/x.png` and `../x.png`).
- Fresh project to room by calls only: same file.
- Shared collision function: `core/test/tilegen.test.ts`.
- Docs and AGENTS.md: checked by reading.
