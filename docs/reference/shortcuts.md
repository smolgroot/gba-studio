# Keyboard shortcuts

## Everywhere

| Key | Action |
| --- | --- |
| `Ctrl+Z` | Undo in the open document (up to 200 steps; 100 in the pixel editor) |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+B` | Hide or show the Project panel |

## Desktop app

| Key | Action |
| --- | --- |
| `Ctrl+O` | Open a folder |
| `Ctrl+W` | Close the document tab in front |
| `Ctrl+Shift+W` | Close the current project |
| `Ctrl+Tab` | Next project |
| `Ctrl+Shift+Tab` | Previous project |

## Map editor

| Key | Action |
| --- | --- |
| `B` / `E` | Brush / eraser |
| `R` / `G` | Rectangle / fill |
| `I`, or `Alt` + click | Pick a tile from the map |
| `N` | Entities |
| `P` | Play from here |
| `H`, or hold `Space` | Pan |
| `Delete` | Remove the selected entity |
| `Escape` | Stop picking a reference's target on the map |
| Right mouse button | Erase while using the brush or rectangle |
| `Ctrl` + wheel | Zoom |

## Pixel editor

| Key | Action |
| --- | --- |
| `B` / `E` | Pencil / eraser |
| `L`, `R`, `U`, `O` | Line, rectangle, filled rectangle, ellipse |
| `G` | Fill |
| `I`, or `Alt` + click | Pick a colour from the image |
| `H`, or hold `Space` | Pan |
| `[` / `]` | Smaller / bigger brush |
| `X` | Back to the previous colour |
| Right mouse button | Erase with any drawing tool |

## Play panel

| Key | GBA button |
| --- | --- |
| Arrows | D-pad |
| `X` | A |
| `Z` | B |
| `Enter` | Start |
| `Shift` | Select |
| `A` / `S` | L / R |

## Entities list

In a field of an open row of the Play panel's [Entities list](../guide/build-and-play#changing-numbers):

| Key | Action |
| --- | --- |
| `Enter` | Write the value into the running game |
| `Escape` | Leave the field without writing |

While a field has the focus, keys go to it, not to the game.

## Entities page

In the list of types on the [Entities page](../guide/entities#the-list):

| Key | Action |
| --- | --- |
| `Up` / `Down` | Select the type above / below |
| `Home` / `End` | Select the first / last type |
